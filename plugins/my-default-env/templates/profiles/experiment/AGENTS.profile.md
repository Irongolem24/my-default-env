
**profile: experiment** (이미지 생성, 모델 한계 탐색, 멀티모델 루프)
- 생성 1회 또는 같은 설정의 배치 1개 = attempt 1개. 프롬프트 원문, 모델과 버전, 파라미터, 참조 이미지 경로, 결과물 경로, 평가를 빠짐없이 쓴다. "대충 비슷한 설정"으로 뭉개지 않는다.
- 결과물은 `.knowledge/assets/<attempt 파일 stem>/`에 저장하고 attempt 본문에서 링크한다. 이미지와 영상은 git LFS로 추적된다.
- 변형 실험은 새 attempt를 만들고 `derived_from: ["[[이전 id]]"]`로 계보를 잇는다. 무엇을 바꿨는지(변수 1개)를 제목에 쓴다.
- 모델의 한계나 잘 되는 패턴이 반복 관찰되면 finding으로 승격한다 (예: "모델 X는 손가락 6개 오류가 참조 이미지 2장 이상에서 줄어든다", sources에 attempt id들).
